Reproduction in an explicitly disposable, installed Joomla:
python tools/build.py
Install both ZIPs with Joomla extension:install; enable the console plugin.
php tests/transport.php
php tests/inventory.php /path/to/joomla
python tests/connector_http.py --site /path/to/joomla --php /path/to/php
  --certificate /private/path/localhost.crt --private-key /private/path/localhost.key
  --allow-disposable-writes
The final command is one line. It needs php-cgi alongside php and a test certificate
valid for localhost. The test trusts only that supplied certificate. It overwrites
the disposable connector parameters and finally revokes/disables it. Credentials
are random and in memory; no inventory or credentials are written by the test.

Limits: not a production web-server/proxy or public network deployment test.
No second Joomla site or central component yet. One read-only credential per site,
manual configuration; central secure storage, pairing UI, rate limiting, alerts,
updates and backups remain pending. Future Joomla majors/platforms are unverified.
The product is a development prototype, not a finished monitoring service.
