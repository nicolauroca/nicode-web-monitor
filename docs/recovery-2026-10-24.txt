Nicode Web Monitor - interrupted session recovery, 24 October 2026
Package: Nicode.joomla.webmonitor

The evening execution reached its 1800-second gateway limit. Its completed
joint capture and restored files survived; the missing final response did not
mean that no work had occurred. The original diagnostic remains unchanged.

Recovery reused the existing restored tree, without recapturing or overwriting
it. All 9823 files (88074454 bytes), directory entries, lengths and chunk SHA256
digests match the captured manifest. The existing exported database snapshot
was restored into a new isolated database: all 78 schemas and all 969 rows
(compared as multisets, including NULL values) match the snapshot.

A separate clone of the restored files booted against that restored database.
Its frontend and administrator login returned HTTP 200 with expected Joomla
content. Only after the equality checks, the clone configuration was adjusted
for its isolated database/paths, outgoing mail disabled and the connector
disabled. Authenticated administration workflows were not tested. The clone
database was removed and lab ports closed after testing.
